# FAIRSVIA 3D clay icons — colour system

Every icon is one soft-clay body in a single **role colour**, with any
enclosed counter (the tick in `shieldCheck`, the dot in `mapPin`, the X in
`x`) filled by a recessed **cream inlay**. Role per icon: `roles.json`
(generated by `roles.py`, the single place to change a mapping).

| Role | Light body | Dark body | Used for |
|---|---|---|---|
| `brand` (default) | `#1FA7A8` teal | `#2CC0C1` | everything not listed below: pins, map, phone/chat, vehicles, people, time, info |
| `chrome` | `#A8A29B` warm grey | `#8A8580` | quiet navigation chrome, modelled from the Phosphor **Regular** stroke (widened to ~30/256 units, thinner slab, no inlay) so it recedes: arrowLeft/Right/UpRight, arrowsLeftRight, arrowClockwise, caretLeft/Right/Up/Down, x, plus, list, dotsThree |
| `neutral` | `#3C4046` graphite | `#A9AFB8` silver | UI objects: copy, export, sign-out, pencil, search, grid, square/circle, toggle-off, wrench, ruler, note, tray, chat-off, moon |
| `danger` | `#E5484D` coral | `#F0605F` | siren (SOS), warningCircle, calendarX, trash, userMinus, record |
| `success` | `#2BAA6B` green | `#38C27F` | check, checks, checkCircle, sealCheck, calendarCheck, shieldCheck, toggle-on |
| `warning` | `#F2A93B` amber | `#F6B84F` | warning, lightning (surge), gpsSlash, cloudSlash (offline), hourglass |
| `rating` | `#F5C542` gold | `#F7CF5A` | star, sun, moonStars |
| `love` | `#E8577A` rose | `#F06E8D` | heart, handHeart, heartbeat |
| `money` | `#3DBE8B` mint | `#4CD39C` | money, cashRupee, coins, wallet, piggyBank, bank, creditCard, cards, receipt, tag, percent, ticket, chartLineUp, trendUp |
| inlay | `#FFF6E9` cream | `#FFF6E9` cream | counters inside any glyph |

Shading inside one body: side walls are the role colour darkened to 86%, the
face toward the viewer (and the upper part of the body) is lifted to ~114%,
so the front reads as the lit "top face". Hexes above are the base; the
rendered front face lands close to them.

Framing: masters are rendered with the Phosphor live area at 84% of the
frame; composite.py scales each to 92% about the common centre, clamped per
icon so the body keeps a 2% clear border (full-bleed glyphs like piggyBank
end up slightly under 92%), and centres the content horizontally.

Extra names (not yet constants in phosphor_icons.dart; code points checked
by drawing them): arrowLeft U+E058, arrowRight U+E06C, caretLeft U+E138.

Why these choices
- Chrome is warm grey and thin (owner review): solid graphite Fill carets
  read as heavy dark triangles that dominated list rows.
- Graphite for UI objects keeps navigation glyphs quiet next to meaningful ones;
  in dark mode graphite would vanish on `#17181B`, so it flips to silver.
- `shieldCheck` is green (verified / safe), not coral: coral is reserved for
  SOS and destructive/error states so red always means "act now".
- Offline / lost-GPS are amber (degraded, recoverable), not red.
- Dark renders use slightly brighter bodies, a cool rim light and no floor
  shadow (a shadow on a near-black surface reads as a smudge).

Pipeline: `extract.py` (Fill outlines -> svg/ + glyphs.json) -> `roles.py`
-> `render.py` in Blender 4.2 (Cycles/OptiX) -> `composite.py` (contact
shadow, 256 px) -> `sheet.py` (contact sheet in docs/brand/research/).
```
python3 extract.py && python3 roles.py
blender -b -P render.py -- RAW both          # optional icon names after 'both'
python3 composite.py RAW && python3 sheet.py
```
